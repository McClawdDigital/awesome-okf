## What is OKF

**Open Knowledge Format (OKF)** is a universal, vendor-neutral format for representing knowledge as plain markdown files with YAML frontmatter. Launched by [Google Cloud Platform](https://github.com/GoogleCloudPlatform/knowledge-catalog), OKF enables:

- **🤝 Human & Agent Readable** — No SDK needed. An engineer can `cat` a concept; an LLM can ingest it verbatim.
- **📦 Version Controllable** — Bundles live in git. Pull requests, diffs, blame, and review workflows work natively.
- **🔓 Portable & Lock-in Free** — A bundle is a directory. Ship it as a tarball, host in any repo, mount from any filesystem.
- **🧩 Composable** — Concepts link to each other via markdown links, expressing rich relationships.
