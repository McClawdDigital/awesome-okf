# Contributing to Awesome OKF

Thanks for helping grow the OKF ecosystem! This awesome list is curated alongside [BundleDex](https://bundledex.net).

## Adding a Bundle

**The fastest way is to use our [submission form](https://bundledex.net/submit).** We'll review it and add it to both BundleDex and this awesome list.

Alternatively, you can open a pull request:

1. Fork this repository
2. Add your bundle to the relevant section in `README.md`
3. Make sure to link to the **BundleDex listing** (e.g., `https://bundledex.net/bundles/<slug>`)
4. Include the author, star count, and a brief description
5. Submit a PR with a clear title

## Guidelines

- Bundles should follow the [OKF specification](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf)
- Only list publicly accessible bundles
- Provide accurate star counts and descriptions
- Keep descriptions under 120 characters
- Sort within sections by star count (descending)

## Questions?

Open an issue or use the [BundleDex contact page](https://bundledex.net/submit).
